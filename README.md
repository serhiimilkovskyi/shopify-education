## Налаштування Search & Discovery
1. У адмінці: **Застосунки → Search & Discovery → Filters**.
2. Увімкніть потрібні фільтри.
3. Призначте фільтри до колекцій.
4. У редакторі теми для секції колекції переконайтесь, що в блоці **Filters** увімкнено **Enable filtering** (`enable_filtering: true` у `templates/collection.json`).
